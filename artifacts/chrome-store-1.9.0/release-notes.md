# 1.9.0

- Estimate planned Squadrats gains in Analyse route: new Squadrats and Squadratinhos, Yard and Yardinho growth, and larger Übersquadrat and Übersquadratinho squares. Enabled by default when the separate Squadrats extension has loaded its collection; calculations run locally.
- Show compact green E-road badges alongside national road numbers in Finland. Bundled segment-specific OpenStreetMap references keep badges available at overview scales, including the 4 km scale. Adjust visibility with the new Settings slider.
- Fix approved POIs disappearing on routes containing Komoot Highlights whose IDs change between numeric and text representations during recalculation.
- Simplify the Chrome Web Store description around trail colours, route analysis, hazards, Squadrats estimates and road-number badges.

No new extension permissions or host permissions. Chrome users can update through the Chrome Web Store. Manual Chrome and unsigned Firefox ZIPs remain available on GitHub while Firefox Store availability is pending. Store publication is subject to Google's review.
