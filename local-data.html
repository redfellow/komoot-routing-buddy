Local Finland data

Finland data powers map hazards and trail checks without online OSM requests. Release packages install it automatically.

Keep this tab open while importing or updating. Your current data stays available until the new data is ready.

Import a prepared data folder

Select the folder containing manifest.json and its data files. If interrupted, select the same folder to resume.

Updates download roughly 770 MB and take several minutes. Allow several GB of free disk space. You can pause and resume later.
