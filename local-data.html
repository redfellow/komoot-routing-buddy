Local Finland data

Import a prepared Finland snapshot for hazard overlays and trail checks. Select the folder containing manifest.json and its compressed data files.

The current snapshot stays available during import. Keep this tab open until import finishes. After interruption, select the same folder to resume.

Updates use a temporary background tab. Keep it open while running. The source download is approximately 770 MB; preparation took about seven minutes in desktop Chrome, plus download time.
